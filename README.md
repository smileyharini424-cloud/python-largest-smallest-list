# Largest and Smallest in a List

## Explanation

This program finds the largest and smallest values from a list of numbers.

## Problem Statement

Write a Python program to determine the maximum and minimum elements in a list.

## Features

* Accepts a list of numbers
* Finds the largest number
* Finds the smallest number
* Displays the results

## How It Works

The program uses Python's built-in `max()` and `min()` functions.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* `max()`
* `min()`

## Program Flow

1. Read the numbers
2. Convert them into integers
3. Find maximum
4. Find minimum
5. Display results

## Sample Input

```text
10 25 3 45 18
```

## Sample Output

```text
Largest number: 45
Smallest number: 3
```

## Time Complexity

O(n)

## Space Complexity

O(n)
